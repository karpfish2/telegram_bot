
# Simple TeleBot

A lightweight Telegram bot built with the **Telebot** library in Python. This bot can send photos, audio files, and features interactive inline buttons for a seamless user experience. Perfect for beginners looking to explore Telegram bot development or for anyone wanting a simple, customizable bot template.

## Features
- 📸 **Send Photos**: Share images directly through the bot.
- 🎵 **Send Audio**: Deliver audio files to users.
- 🔘 **Inline Buttons**: Beautiful and interactive inline keyboards for user navigation.
- 🚀 **Easy to Customize**: Modular code structure for quick modifications.
